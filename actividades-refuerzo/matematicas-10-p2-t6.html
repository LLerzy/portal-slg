Parte 1. Repaso conceptual

Los episodios de los camellos y de los panes se inspiran en el libro El hombre que calculaba (Malba Tahan), donde Beremiz Samir resuelve situaciones con ingenio matemático. Aquí se usan con datos adaptados para practicar el razonamiento: no basta con obtener resultados, hay que poder justificarlos.

1. Ejemplo, contraejemplo y demostración

TérminoQué esQué permite
ConjeturaAfirmación que parece cierta a partir de algunos casosPlantear una hipótesis
EjemplosCasos particulares que cumplen la afirmaciónApoyar la conjetura, pero no demostrarla

DemostraciónArgumento válido para todos los casos (con letras o con una propiedad general)Asegurar que la afirmación es verdadera

2. Herramientas para demostrar

Par: \(2k\)  ·  Impar: \(2k+1\)  ·  Tres enteros consecutivos: \(n,\ n+1,\ n+2\)
Entre dos enteros consecutivos siempre hay uno par. Un número es múltiplo de 3 si se puede escribir como \(3\cdot(\text{entero})\).

3. Fracciones de una cantidad

Para hallar una fracción de una cantidad se multiplica: \(\frac13\) de 36 es \(\frac13\cdot36=12\). Las fracciones de un reparto se suman con común denominador: \(\frac12+\frac13+\frac19=\frac{9}{18}+\frac{6}{18}+\frac{2}{18}=\frac{17}{18}\).

Parte 2. Ejemplos resueltos

Ejemplo 1 · Demostrar una afirmación

Afirmación: la suma de tres enteros consecutivos es siempre múltiplo de 3.

Sean \(n,\ n+1,\ n+2\) tres enteros consecutivos. Su suma es \(n+(n+1)+(n+2)=3n+3=3(n+1)\), que es 3 por un entero. Por tanto, es múltiplo de 3 para cualquier \(n\). (Probar con \(1,2,3\), \(4,5,6\)… daría evidencia, pero no una demostración.)

Ejemplo 2 · Refutar con un contraejemplo

Afirmación: “si \(n\) es primo, entonces \(2^n-1\) es primo”.

Para \(n=2,3,5,7\) se obtiene \(3,\ 7,\ 31,\ 127\), todos primos: ¡parece cierta! Pero para \(n=11\) (primo), \(2^{11}-1=2047=23\cdot89\) no es primo. Este único caso es un contraejemplo y basta para declarar falsa la afirmación.
