Conectar la fuente de datos

Este panel busca automáticamente un archivo llamado comparativosimulacros.csv en la misma carpeta que index.html. Si estás viendo este mensaje, ese archivo todavía no está ahí (o estás probando el archivo localmente con doble clic, donde el navegador bloquea esa lectura por seguridad — pruébalo ya publicado en GitHub Pages).

  1. En Google Sheets, abre la hoja Comparativosimulacros → Archivo → Descargar → Valores separados por comas (.csv).
  2. Renombra el archivo descargado a exactamente comparativosimulacros.csv.
  3. Súbelo a tu repositorio de GitHub, en la misma carpeta que index.html. Cada vez que actualices resultados, repite estos pasos y reemplaza el archivo en GitHub.

¿Prefieres que el panel lea siempre la versión más reciente sin subir el CSV a mano? Pega abajo el enlace de Archivo → Compartir → Publicar en la Web (formato CSV), o edita CONFIG.csvUrl en el archivo para dejarlo guardado.
